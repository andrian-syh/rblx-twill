## One field changes what a bad message costs

Twill used to encode remotes through a bundled library. It no longer does.
`Twill.Net` carries its own wire format, and the whole design turns on one
field:
**every call carries the length of its own body.**

That field is four bytes per call, and it buys three things at once.

A corrupt call stops at its own frame. The reader steps to where the body ended
whether or not reading it worked, so a call that arrives mangled costs itself
and nothing else:

```text
1 = payload1  |  2 = refused  |  3 = payload3
```

A refused call is never read. Rate limiting can skip past a call it has already
decided to drop, so the decoding is not paid for on behalf of the caller being
turned away.

And a hostile length is a bounded problem rather than an open one. It is checked
against the frame it arrived in before anything is allocated for it.

## Declaring with `Net.Types`

```luau
local Net = require("@game/ReplicatedStorage/Twill/Net")
local Types = Net.Types

local buy = Net.Declare("BuyItem", { Types.String(32) }, { Types.Boolean })
local aim = Net.DeclareUnreliable("Aim", { Types.Vector3F32 })
```

Both sides compile the same declaration, so nothing describing a type is sent. A
struct sends its values and not its field names. A thousand booleans is a
hundred and twenty-five bytes.

`Types.String(32)` is a ceiling, and it is enforced at the sender:

```text
Twill.Net: BuyItem argument 1 is 300 bytes, past its ceiling of 32
```

Previously a string past 255 bytes wrapped its length prefix and quietly
corrupted everything written after it. A sender's own mistake now surfaces at
the sender.

## Things that used to be silent

**Half floats** dropped very small values to zero, or worse, wrote garbage for
them. They now round-trip subnormals, both infinities, and NaN.

**A skewed CFrame** was flattened without a word by the compact rotation formats.
`Types.CFrameRot` now refuses one, and `Types.CFrame` keeps all twelve
components:

```text
Twill.Net: a CFrameRot is not a plain rotation, so it needs the full CFrame type
```

**A constant outside a declared set** used to arrive as `nil` on the far side.
It is refused on the way out.

**A union tag** naming a member the union was never declared with used to select
whichever decoder that number happened to name. It is refused.

## Two things a client can no longer say

`Types.Player` is refused in an argument list. A player named on the wire is a
player the sender chose, and the caller already arrives as your handler's first
argument, from the engine:

```text
'Trade' argument 1 names a player, which only the server may say;
the caller is given to the handler already
```

And only the client asks. The server never waits on an answer from a client, so
there is no server thread a peer's message can reach. The number identifying a
question is the asker's own and is looked up only in the asker's own table.

An `Instance` from a client is still allowed, and still the client's choice. The
decoder proves its shape: that it exists, that it is the class you named. It
does not prove the caller may touch it. That belongs in `Validate`, where it is
visible.

## Metering happens before reading

The bytes of a whole message are weighed before it is opened. Then each call is
metered by name after four bytes of header and before its arguments are decoded.

Batching many calls into one message therefore costs what those calls actually
weigh, rather than what one message costs.

A joining player is metered from their first call. Their standing is created the
moment it is needed rather than by a hook that can lose a race against a message
arriving in the same frame.

## Boot order is not load bearing

A remote declared on a client is given its number by the server, and that
arrives a moment later. A call made before then is held and sent once the number
arrives.

```luau
Net.OnReady(function()
	-- everything declared here knows its number
end)
```

Replication used to poll for up to thirty seconds before asking for its first
snapshot. It waits on this instead.

## Upgrading

Two changes, both mechanical.

```luau
-- before
local Packet = require("@game/ReplicatedStorage/Twill/Packages/Packet")
Net.Declare("BuyItem", { Packet.String }, { Packet.Boolean8 })

-- after
local Types = Net.Types
Net.Declare("BuyItem", { Types.String(32) }, { Types.Boolean })
```

`Twill.Packet` is gone from the root table, and the bundled library is no longer
shipped. `Handle`, `IsHandled`, `Get`, and `List` are unchanged, and `List` now
reports each remote's number alongside its signature.
